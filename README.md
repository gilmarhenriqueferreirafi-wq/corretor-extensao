# Corretor de Extensão

Extensão de navegador para auxiliar na correção e melhoria de textos.

## Instalação local

1. Abra a página de extensões do navegador.
2. Ative o modo do desenvolvedor.
3. Escolha **Carregar sem compactação**.
4. Selecione esta pasta.

## Tecnologias

JavaScript, HTML, CSS e WebExtensions.
